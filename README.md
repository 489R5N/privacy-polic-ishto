# Privacy Policy for Ishto

This repository hosts the privacy policy for the mobile game **Ishto**.

## Live URL
**https://489R5N.github.io/privacy-polic-ishto/**

## Files
- `index.html` — Privacy policy (served by GitHub Pages)

## Setup GitHub Pages
1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** → **/(root)**
4. Save → Wait 1–5 minutes

## Update Policy
Edit `index.html` and push to `main`. Changes deploy automatically.
