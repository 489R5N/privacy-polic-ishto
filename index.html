1. Data We Collect

We do not collect personally identifiable information (PII).

Automatically Collected (Anonymous)

  • Device information: model, OS version, unique device identifiers (IDFA/AAID)
  • Gameplay data: level progress, session length, feature usage
  • Technical data: IP address (briefly for connectivity), crash logs, performance metrics

Optional Data (With Consent)

  • Email address (support requests, newsletters)
  • Username/display name (leaderboards, social features)

2. How We Use Data

  • Game functionality: Save progress, sync across devices
  • Analytics: Improve gameplay, balance difficulty, fix bugs
  • Advertising: Show relevant ads (via AdMob/Unity Ads)
  • Legal: Comply with laws, enforce terms, prevent fraud

4. Data Retention

5. Your Rights (GDPR/CCPA)

  • Access: Request copy of your data
  • Deletion: Request erasure (contact us)
  • Opt-out: Disable analytics/ads in game settings
  • Portability: Export your data in readable format

6. Children's Privacy (COPPA)

Our game is not directed at children under 13 (or 16 in EU). We do not knowingly collect data from children. If you believe we have, contact us immediately for deletion.

7. Data Security
